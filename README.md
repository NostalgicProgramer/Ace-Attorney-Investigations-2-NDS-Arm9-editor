# Ace-Attorney-Investigations-2-NDS-Arm9-editor
English: A tool created in Godot 4.4.1 for editing the arm9 of AAI2 for the NDS.

To use the tool, download Godot Engine version 4.4.1, open the project within it, and simply press F6 to run the program.
